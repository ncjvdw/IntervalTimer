# Interval Timer

> Interval timer for timing exercises.

## Overview

Simple but efficient interval timer where you can create custom saveable lists.

## Features

* Add exercises with a time to countdown from
* Save lists of exercises to use them again later
* Everything is saved locally
* Says the name of the exercise at the start of each timer

## Tech Stack

* HTML
* CSS
* Javascript
