    Online Interval Timer for Workouts

    Use this free interval timer to create custom workout routines with your own exercises and durations. It works well for HIIT, circuit training, running, boxing, and home workouts.

    How to Use the Interval Timer

    Add an exercise, choose how long it should last, and add as many exercises as you need. Save your list for later, then start the timer when you're ready and follow each interval as it progresses.
